# 이음

빅콘테스트 2026 사회적 고립 부문 출품작. 지자체 담당자가 어느 동의 어떤 집단부터 살펴보고, 어떤 지원사업으로 연결할지 정하도록 돕는 화면이다.

- 화면: https://ieum-pink-psi.vercel.app
- 연락·외출 모델(M3): https://github.com/KangKyuC/bigcontest2026

화면에 나오는 사람은 모두 가상 페르소나다. 동 × 성별 × 나이대 집계값에서 만든 인물이고, 숫자는 실제 주민 수가 아니다.

## 어떻게 판단하나

1. 강남 220개, 춘천 250개 집단에서 연락·외출(M3의 서울 동년배 백분위)과 주말 사람 흐름(SK 유동, 평일 유입 보정)을 본다. 하나라도 하위 20%면 페르소나로 만든다. 연락이 상위 20%인 집단은 뺀다.
2. 페르소나마다 강남 37개, 춘천 17개 사업의 신청 조건(나이, 가구, 소득, 대상, 신청 방법, 운영 시간, 지역, 모집 기간)을 하나씩 대조한다.
3. 7개 지원 분야마다 막힌 이유를 나눈다. 갈 곳이 없는지, 방식이 안 맞는지, 공고에 정보가 없는지, 모집이 끝났는지.
4. 신호와 공백으로 단계를 정한다. 개인 신호가 하위 5%이거나 하위 20%가 두 개 이상이면 신호가 강하다. 신호가 강하고 공백이 있으면 1단계, 공백이 없으면 2단계, 신호가 보통이면 3·4단계다. 주말 사람 흐름은 동 전체 값이라 그것만으로는 강하다고 보지 않는다.
5. 조건을 하나씩 바꿔 다시 판정해서(저녁·주말 회차, 1인가구 요건, 소득 요건, 나이 상한, 신청 방법) 몇 명에게 길이 열리는지 센다. 이것이 정책 추천이 된다.

학습한 모델이 아니라 정해 둔 규칙이라 같은 입력이면 늘 같은 결과가 나온다. 규칙은 `ieum/agent.py`의 `level_of`, 시험은 `tests/test_rules.py`에 있다.

## 구조

```
ieum/            판단 파이프라인
  engine.py        사업 조건 대조
  personas.py      페르소나 선정
  recommend.py     사업 추천 순서
  agent.py         단계, 할 일, 판단 기록
  policy.py        정책 추천
  sources.py       입력 읽기
  export.py        화면용 JSON 쓰기
tests/           규칙 시험, 결과 JSON 정합성 시험, 전체 실행 시험(입력이 있을 때만)
dashboard/       화면 (React, Leaflet, Vite). 서버 없이 public/data의 JSON만 읽는다
scripts/deploy.sh
```

## 개발

[uv](https://docs.astral.sh/uv/)와 Node 22가 필요하다.

```sh
make install   # uv sync + npm ci
make dev       # 화면 http://127.0.0.1:5173
make lint      # ruff, eslint, prettier, tsc
make test
```

화면만 고칠 때는 파이썬이 필요 없다. 결과 JSON이 저장소에 들어 있다.

판단 규칙을 고쳤다면 결과를 다시 만든다. 이때는 `data/` 입력이 필요하다(아래 참고).

```sh
make data      # 페르소나 선정 → 화면용 JSON
make test      # 입력이 있으면 전체 실행 시험까지 돈다
```

`IEUM_DATA`로 입력 폴더를 바꿀 수 있다. 패키지 버전은 공개 화면을 만든 버전에 고정했다. pandas 버전이 바뀌면 좌표 끝자리가 달라진다.

## 입력 자료

`data/`는 저장소에 없다. M3 220셀 결합 입력과 SK 집계는 대회 제공 자료로 만든 것이라 재배포하지 않는다. 사업 조건표, 행정동 경계, 동 인구도 지금은 로컬에만 있다. 그래서 이 저장소만으로는 `make data`를 돌릴 수 없고, CI는 규칙 시험과 결과 JSON 시험만 돈다.

## 알려진 문제

- 화면에 "연락·외출 예측"이라고 적혀 있지만 값은 M3의 관측 백분위다. 발표자료와 맞추려고 발표 뒤에 "연락·외출 집계"로 고친다.
- 춘천은 서울 통신 자료가 없어서 신호가 주말 사람 흐름 하나뿐이다. 그래서 전원 3단계다. 교동(한림대)과 효자2동(강원대)은 대학가 영향일 수 있다.
- 동별 페르소나는 혼자 산다고 가정한다. 가족과 산다고 바꿔도 닫히는 분야는 주거·안전뿐이다.
- 60세 미만은 평일 낮에 못 간다고 가정한다. 강남 결론은 이 가정과 상관없고, 춘천의 "저녁·주말 회차를 열면 29명"은 일하는 사람 기준이다.
- 단계가 맞는지 외부 기준으로 검증하지 않았다.
